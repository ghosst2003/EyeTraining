# 眼睛训练系统

一个基于 Web 的眼睛对齐训练工具，通过调整文字垂直位置来训练眼睛的聚焦能力。

## 功能特点

- **视力表标准字体大小**：0.1 ~ 2.0（4 米标准）
- **中英文训练文本**：支持中文和英文句子
- **随机跳动**：文字以第一个字为基准随机上下跳动
- **拖拽滚动**：文本过长时可鼠标拖拽横向滚动
- **训练计时**：可配置训练时长

## 运行环境要求

- 任意现代浏览器（Chrome / Safari / Edge / Firefox）
- Python 3（用于启动本地服务器）

## 快速运行

### 方法一：自动脚本（推荐）

**macOS / Linux：**
```bash
./start.sh
```

**Windows：**
```cmd
start.bat
```

### 方法二：手动运行

```bash
# 进入项目目录
cd EyeTraining

# 启动本地服务器
python3 -m http.server 8888

# 浏览器打开
# 访问 http://localhost:8888
```

## 使用说明

1. **配置界面**
   - 选择语言（中文 / English）
   - 选择视力大小（0.1 ~ 2.0）
   - 选择训练时长
   - 点击"开始训练"

2. **训练界面**
   - 点击文字可调整其垂直位置
   - 第一个字为基准，不可点击
   - 点击"检查"验证对齐情况
   - 错误文字标红，正确后按钮变为"下一个"
   - 文本过长时可鼠标拖拽滚动
